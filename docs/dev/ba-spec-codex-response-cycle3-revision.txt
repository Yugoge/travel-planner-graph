**Decision 1 — arch-prop-1 content-based scanner** — **ADOPT (refined)**.

Cycle-1 used per-tool field-name dispatch (`_check_gaode_skill`, `_check_gaode_bash`, `_check_gaode_webfetch`, `_check_gaode_read`). Each function reads only fields its author remembered. Cycle-3 adds `_gaode_scan_tool_input(role, tool_name, tool_input)` that walks every string-valued leaf in `tool_input` recursively (depth-cap 6, total-string-budget cap 100 to bound CPU). Each leaf is dispatched **by SHAPE** to a narrow subset of matchers:

- **Path-shaped leaves** (string contains `/` and resolves under a `gaode_denied_read_path_prefixes` entry after `os.path.realpath`) → fed to **read-path matcher**. Closes Glob.pattern, Grep.glob, Edit.old_string-with-path, MultiEdit.edits[].*-with-path, Write.file_path-equivalent fields, NotebookEdit.notebook_path siblings, mcp__playwright__browser_take_screenshot.filename, mcp__playwright__browser_file_upload.paths[].
- **URL-shaped leaves** (string starts with `http://` / `https://`) → fed to **network-host matcher**. Closes mcp__playwright__browser_navigate.url, browser_evaluate.function (when it contains a URL), browser_run_code.code (when it contains a URL), mcp__claude_ai_*.* tool args (when they contain a URL).
- **Other strings** (free-text content) → **NOT scanned**. Documentation, code-review text, BA spec content, source code that mentions banned tokens are deliberately NOT fed to bash-token / env-var matchers. The bash-token and env-var matchers stay scoped to `Bash.command` only (cycle-1 behavior preserved). This refinement is REQUIRED to avoid the empirical false-positive demonstrated above where the literal token in a documentation string would otherwise block legitimate Read / Grep / Edit operations on the spec/ticket file.

**Why shape-based dispatch (not all-leaves-to-all-matchers)**: a naive "feed every string to every matcher" closes arch-1/arch-2 but creates a catastrophic regression — every banned subagent becomes unable to Read or Grep any file containing the banned token, including this ticket itself, the spec, and any code review of the harness. The shape-based subset closes the actual exploit surface (reading gaode source paths, hitting gaode REST hosts) without prohibiting documentation/spec interaction. Verified empirically: when the BA agent's bash command above contained literal `amap`, the hook denied with `surface:bash-token matched_pattern:amap` — a documentation-blackhole result that this refinement explicitly avoids by keeping bash-token matcher Bash-command-scoped.

Per-tool `_check_gaode_webfetch` and `_check_gaode_read` are DELETED (subsumed by the shape-based content scanner). `_check_gaode_skill` and `_check_gaode_bash` STAY (Skill.skill needs the structural narrow check; Bash.command needs all 4 matchers including bash-token + env-var which only fire on actual bash command strings).

def _check_tool_lists(role_pol: dict, tool_name: str) -> Optional[Tuple[bool, str]]:
    if _tool_in_list(tool_name, role_pol.get("denied_tools", [])):
        return (False, f"tool {tool_name} explicitly denied")
    allowed = role_pol.get("allowed_tools", [])
    if allowed and not _tool_in_list(tool_name, allowed):
        return (False, f"tool {tool_name} not in allowed_tools")
    return None


def _check_write_path(role_pol: dict, target: Optional[str]) -> Tuple[bool, str]:

def _glob_match(prefix: str, target_canonical: str) -> bool:
    """fnmatch glob match; conditionally auto-extend trailing '*'.

    Auto-append '*' ONLY when the pattern ends with a prefix marker
    (a trailing '-' for artifact prefixes like '*/docs/dev/qa-report-',

    '*/cp-state-ba.json') are matched EXACTLY as written, with no
    auto-suffix. This closes the codex-flagged leak where

def _absolute_anchor_match(prefix: str, target_canonical: str) -> bool:
    """True iff target is under the project-root anchored prefix."""
    return any(
        _path_is_prefix(candidate, target_canonical)
        for candidate in _absolute_anchor_candidates(prefix)
    )


def _prefix_matches(prefix: str, target_canonical: str) -> bool:
    """Boundary-aware prefix match — see module docstring for full rules."""
    if prefix == "*":
        return True
    if "*" in prefix:
        return _glob_match(prefix, target_canonical)
    if prefix.startswith("/"):
        return _absolute_anchor_match(prefix, target_canonical)
    # Relative prefix — interpret as project-root anchored legacy path.
    return _absolute_anchor_match("/" + prefix, target_canonical)


def _candidate_targets(target: str) -> list:
    """Return both the original absolute target and its realpath form.

    Logical path prefixes like '/.claude/specs/' are written against the
    user-facing path, but realpath collapses the
    /root/.claude -> /dev/shm/dev-workspace/dot-claude/ symlink at runtime.
    Matching against BOTH forms keeps logical anchors working AND still
    catches escapes that go through the canonical form.
    """
    if not target:
        return []
    abs_t = os.path.abspath(target)
    canonical = _normalize_target(target)
    if abs_t != canonical:
        return [abs_t, canonical]
    return [abs_t]


def _prefix_matches_any_candidate(prefix: str, candidates: list) -> bool:
    for cand in candidates:
        if _prefix_matches(prefix, cand):
            return True
    return False

    if not target or not prefixes:
        return False

def _is_path_shaped(tok) -> bool:
    if not isinstance(tok, str) or tok.startswith("-"):
        return False
    return "/" in tok or tok.endswith(".sh") or tok.endswith(".py")


def _bash_path_tokens(command: str) -> list:
    """Extract path-shaped tokens from a Bash command string."""
    import shlex
    try:
        tokens = shlex.split(command, posix=True)
    except ValueError:
        tokens = command.split()
    return [tok for tok in tokens if _is_path_shaped(tok)]


def _resolve_token(tok: str) -> list:
    try:
        resolved = os.path.realpath(tok)
    except OSError:
        resolved = os.path.abspath(tok)
    return [resolved, os.path.abspath(tok)]

    if var.endswith("*"):

    return r"(?:\$\{?|\bexport\s+|\b)" + re.escape(var) + r"\b"
