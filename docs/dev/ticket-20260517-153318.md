## Edge Cases & Risks

1. **Token bleed into candidates sidebar** (Codex finding 1, in-scope risk): Updating global `:root` tokens (`--bg-page`, `--border`, `--text-muted`, `--text-subtle`) will affect `.pane-candidates` which uses these tokens. Fix required: add `.pane-candidates` override block restoring the old values. This is in scope as a prerequisite to R1.
2. **Active-row hover regression** (Codex finding 2): `.day-row:hover` with `rgba(55,53,47,0.03)` must be scoped as `.day-row:hover:not(.day-row--active)` — otherwise hovering an active row briefly changes its background.
3. **Stale mobile border-top rule** (Codex finding 5): After removing the base `.pane-middle { border-top }`, the mobile override at `web/css/main.css:494` (`border-top-width: 4px`) becomes a dangling rule that re-introduces a border. Must be deleted together.
4. **UTC date parsing** (Codex finding 6): `new Date("2026-06-20")` parses as UTC midnight and renders as the prior day in US time zones. Use regex + `Date.UTC()` to parse components, format with `Intl.DateTimeFormat` in UTC timezone.
5. **Gap compounding** (Codex finding 9): `.day-heading` lives inside `.timeline-slots`; if container `gap: 32px` is used, it applies above the heading too. Solution: set `gap: 0` on `.timeline-slots`, use `margin-top: 32px` on `.slot + .slot`, keep `.day-heading { margin: 0 0 24px 0 }`.
6. **SLOT_LABELS mutation** (Codex finding 10): `SLOT_LABELS` feeds `_buildCandidateGroup()` in the candidates sidebar (out of scope). Adding emojis there would contaminate the sidebar. Use a separate `SLOT_TITLE_EMOJI` map and `_timelineSlotLabel()` helper.
7. **`.slot-title` dual declaration** (Codex finding 11): `.slot-title` is declared at `main.css:237` (typography) and again at `main.css:354` (layout). The border-bottom separator must go on `.slot-header`, not `.slot-title`, to span the full header row width.

   ```js
   function _formatDayHeadingDate(isoDate) {
     const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(isoDate || "");
     if (!m) return "";
     const dt = new Date(Date.UTC(+m[1], +m[2] - 1, +m[3]));
     const parts = new Intl.DateTimeFormat("en-US", {
       timeZone: "UTC", month: "short", day: "numeric", weekday: "short",
     }).formatToParts(dt);
     const get = (type) => parts.find((p) => p.type === type)?.value;
     return `${get("month")} ${get("day")} (${get("weekday")})`;
   }
   ```
