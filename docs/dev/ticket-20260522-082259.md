## Edge Cases & Risks

- **Backward-compat**: PLAN data trips with no `editorDay` must still render. The `edAcc = editorDay && editorDay.accommodation` null-guard must be in place before computing `selectedAccId` in Bug 4 fix.
- **Bug 3 v2-shape requirement**: The synthesized option object pushed into `options[]` must use v2 field names (`name` not `name_base`, `location_summary` not `location_base`, `cover_image`). Using PLAN field names causes `adaptV2Option()` at L1940 to misread them, producing blank candidate cards.
- **Bug 3 tap-to-select path**: `applyBridge` (L2800) is the code path for tap-to-select (pendingSelection). If only `bridge` is patched, the hotel-disappearance bug persists on touch/click interaction. Both must be patched.
- **Bug 4 scope**: `selectedAccId` currently only exists inside the badge IIFE at L1300. Moving its computation to before the `<div>` is safe because all the same variables (`editorSelections`, `editorDay`, `day`) are in scope at L1262.
- **Bug 1 scope**: The `candidateCardStyle` helper must live in a scope accessible to `CandidatesSidebar` (outside `KanbanView`). It is a module-level helper, like `cardStyle` which is inside `KanbanView`'s IIFE. Define `candidateCardStyle` either as a module-level function or inside `CandidatesSidebar`.
- **Section 8 warning**: Per spec Section 8 — dev must run verification greps before declaring complete to avoid the 3-close-debate pattern from prior cycles.
