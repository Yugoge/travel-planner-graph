## Root Cause Analysis

**Symptom**: Jinli Ancient Street (锦里古街) appears in both attractions.json and entertainment.json with identical time (16:12-17:30), both marked as non-optional

**Root Cause**: plan-validate.py check_cross_agent() function lacks POI time conflict detection. Current cross-agent checks only validate: day count consistency, date consistency, location consistency, budget sum consistency. No logic exists to detect when the same POI (or different POIs with identical times) appears across multiple agent files.

## Implementation

**Approach**: Added POI time conflict detection to check_cross_agent() function in plan-validate.py. Collects all POIs from attractions, entertainment, shopping, meals per day, then checks for time conflicts (identical or overlapping).

**Files Modified**:
- `scripts/plan-validate.py` - Extended check_cross_agent() function (lines 943-1057, +114 lines)

**Implementation Details**:

**Two-Tier Validation Rules**:
1. **Rule 1 (HIGH)**: Identical time + both non-optional → HIGH severity error (blocks save)
2. **Rule 1b (INFO)**: Identical time + at least one optional → INFO (acceptable alternative)
3. **Rule 2 (MEDIUM)**: Overlapping time → MEDIUM severity warning

**POI Sources**:
- attractions.json: `data.days[].attractions[]` array
- entertainment.json: `data.days[].entertainment[]` array
- shopping.json: `data.days[].shopping[]` array
- meals.json: `data.days[].breakfast/lunch/dinner` named keys

**Error Handling**:
- Skips POIs with missing or invalid `time` field
- Handles missing `time.start` or `time.end` gracefully
- Uses `.get('optional', False)` default for missing optional field
