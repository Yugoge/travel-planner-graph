## Architecture Clarification

**timeline object**: Contains ALL activities including inter-city transport (train D5121), intra-city transport (taxi), meals, attractions, entertainment, shopping, hotel check-in/out

**travel_segments array**: Contains ONLY intra-city transport for UI rendering of short hops between consecutive activities (taxi to restaurant, metro to attraction, walk between nearby POIs)

**location_change field**: Marks inter-city transport in transportation.json that should appear in timeline but NOT in travel_segments

**Separation of concerns**: timeline = comprehensive schedule, travel_segments = UI rendering of local movement
