### Cycle 1 (BA analysis complete — 2026-04-17)

**Current state**: Two parallel merge paths exist in the save pipeline:

1. `scripts/save.py` has two argparse flags:
   - `--merge-days` (L653): day-level replacement — whole day object overwrites existing
   - `--merge-slots` (L657): slot/key-level merge — only keys present in update overwrite
   - Mutual exclusion guard at L675

2. `scripts/lib/json_io.py` has two functions:
   - `merge_agent_days()` (L336-384): full day replacement
   - `merge_agent_slots()` (L387-453): key-level merge within each day

3. `scripts/save.py` internal helpers:
   - `_merge_existing_data()` (L445-454): wraps `merge_agent_days`
   - `_merge_existing_slots()` (L457-469): wraps `merge_agent_slots`
   - `_prepare_agent_data()` (L498-511): branches on `merge_days` vs `merge_slots`

4. Agent flag usage:
   - 6 POI agents use `--merge-slots`: meals.md:294, accommodation.md:298, attractions.md:292, entertainment.md:272, shopping.md:301, cafe.md:228
   - 3 agents use `--merge-days`: timeline.md:542, transportation.md:270, budget.md:211

5. `.claude/commands/review.md` references `--merge-days` at lines 804-805 and 1353-1354

**Problem**: Two merge paths = two ways to get it wrong. Any new agent or prompt edit could use the wrong flag and cause silent data loss. The distinction is unnecessary because slot-level merge produces identical results for complete-day output (timeline/transportation/budget) and is strictly safer for partial-day output (POI agents).

### Cycle 1

**Approach**: Bottom-up deletion and simplification. Removed the two-flag merge system entirely, making slot-level merge the automatic default triggered by file existence.

**Rationale**: merge_agent_slots() was proven safe for all agent types in Cycle 1 QA (spec-20260416-172720). Complete-day payloads (timeline/transportation/budget) through slot-level merge are safe because dict.update() with all keys is identical to replacement. Two flags = two ways to get it wrong for future agents.

**Steps taken**:
1. Deleted merge_agent_days() function body from json_io.py (49 lines)
2. Removed merge_agent_days import from save.py
3. Deleted _merge_existing_data() helper from save.py (10 lines)
4. Simplified _prepare_agent_data(): removed merge_days/merge_slots params, auto-invokes _merge_existing_slots() when file exists
5. Simplified save_single_agent(): removed merge_days/merge_slots params
6. Deleted --merge-days and --merge-slots argparse flags (7 lines)
7. Deleted mutual exclusion guard (3 lines)
8. Cleaned up main() to not pass merge_days/merge_slots
9. Updated all 9 agent .md files: removed merge flags from save commands, replaced CRITICAL comments
10. Updated review.md at lines 804-805 and 1353-1354
11. Updated test file: removed merge_agent_days import, replaced backward-compat test with test_auto_merge_without_flags
12. Updated docstrings in json_io.py and test file

**Result**: All 8 tests pass. --help shows no merge flags. grep confirms complete removal across all files.
