## Edge Cases & Risks

1. **Stable container contract**: `#candidates-groups` and `#timeline-slots` must be present in the DOM from page load. If tab switching removes them, drag.js and mobile.js lose event listeners silently. Fix: both containers are always mounted; only the tab-content parent divs use `hidden` toggle.

2. **`renderApproveButton()` null crash**: `web/js/state.js:512-523` accesses `btn.disabled` with no null guard. If `#approve-day-btn` is missing, this throws. Fix: approve-day-btn lives inside the Timeline tab content area, always mounted (tab shows/hides the parent, not the button itself). Add `if (!btn) return;` guard as defense.

3. **`renderBudget()` must see mounted IDs**: budget.js uses `getElementById("budget-trip-total")` etc. These must be in the DOM (not just created lazily) when `renderBudget(state)` is called. Fix: Dashboard tab content is statically in the HTML; renderBudget runs as part of renderAll() which fires after init.

4. **`_wireDayPicker()` removal**: state.js:116 calls `_wireDayPicker()` from init(). This must be replaced with `renderDaysPanel()` + delegated click wiring. The old `#day-select` element must be removed from HTML and all references in state.js updated.

5. **`_renderDayPickerOptions()` is called from `renderAll()`**: Any call to `renderAll()` will hit `_renderDayPickerOptions()` which does `document.getElementById("day-select")` — will throw if the element is removed. Replace both functions together.

6. **Mobile pane IDs after restructure**: `mobile.js:53-60` and `mobile.js:156-159` iterate `["candidates","timeline","budget"]` pane IDs. New pane IDs are `["middle","candidates"]` (Days is sticky on mobile, no pane-days tab). Both locations must be updated together.

7. **Days panel — accommodation with no selected option**: `_deriveCityName()` falls back to `day.city_name`; already guarded in prior cycle. Reuse the function verbatim.

8. **Middle tab — default active tab**: On page load, default to Timeline tab active (the primary editing surface), not Dashboard.

9. **Approve button visibility**: When Dashboard tab is active, the approve-day-btn should be visually hidden (not disabled) to avoid confusing users. Use CSS `display:none` on the Timeline tab pane when Dashboard is active.

10. **CSS column separation without borders**: Left and right columns use `var(--bg-page)` (#f7f6f3) background; middle uses `var(--bg)` (#ffffff). The grid gap provides visual separation. No box borders on columns.

**M5 — renderDaysPanel() in state.js:**
```
function renderDaysPanel() {
  const container = document.getElementById("days-list");
  if (!container) return;
  container.innerHTML = "";
  for (const day of state.days) {
    const dayN = day.day || day.day_number;
    const cityName = _deriveCityName(day);
    const row = document.createElement("button");
    row.className = "day-row" + (dayN === state.ui.active_day ? " day-row--active" : "");
    row.dataset.dayN = String(dayN);
    row.textContent = cityName ? `Day ${dayN} · ${cityName}` : `Day ${dayN}`;
    row.addEventListener("click", () => setActiveDay(dayN));
    container.appendChild(row);
  }
}
```
Wire once in `init()` after _fetchTrip: replace `_wireDayPicker()` call with `renderDaysPanel()` call. Add `renderDaysPanel()` to `renderAll()` (replaces `_renderDayPickerOptions()`).

**M6 — middle tab wiring in state.js (one-time in init):**
```
function _wireMiddleTabs() {
  document.querySelectorAll(".middle-tab").forEach(btn => {
    btn.addEventListener("click", () => _activateMiddleTab(btn.dataset.tab));
  });
}
function _activateMiddleTab(tab) {
  document.querySelectorAll(".middle-tab").forEach(b =>
    b.setAttribute("aria-selected", b.dataset.tab === tab ? "true" : "false")
  );
  document.getElementById("tab-dashboard").hidden = (tab !== "dashboard");
  document.getElementById("tab-timeline").hidden = (tab !== "timeline");
  if (tab === "dashboard") renderBudget(state);
}
```
Default active tab on init: "timeline" (call `_activateMiddleTab("timeline")` once from `_wireGlobalControls()`).
