## Technical Hints

- **ITEM 1 implementation hint**: the existing `_duplicate_transit_findings` builds a `seen: dict[(name, day_idx)] -> list[source_label]` via `_collect_transit_keys`. The cross-file narrowing predicate is: `len(set(sources)) >= 2 AND any(s.startswith('transportation.') for s in sources) AND any(s.startswith('timeline.') for s in sources)`. Existing ≥3-source check stays as-is and produces FAIL; the new 2-source-cross-file check emits WARN. The two checks are independent — a triple-duplication still produces one FAIL (not also a WARN for the 2-source subset).
- **ITEM 2 implementation hint**: each `entry._isAlternative` read is in the falsy branch of `(entry.optional || entry._isAlternative)`. Since `entry._isAlternative` is never assigned (verified across the codebase), the expression `(entry.optional || entry._isAlternative)` always evaluates to `entry.optional`. Surgical replacement:
  - Line 2993: `(entry.optional || entry._isAlternative) ? 'dashed' : 'solid'` → `entry.optional ? 'dashed' : 'solid'`
  - Line 3043: `{(entry.optional || entry._isAlternative) && showDetails && (` → `{entry.optional && showDetails && (`
  - Line 3047: `background: entry._isAlternative ? '#edf2fc' : '#f5f5f3',` → `background: '#f5f5f3',`
  - Line 3049: `color: entry._isAlternative ? '#2b63b5' : '#9b9a97',` → `color: '#9b9a97',`
  - Line 3053: `{entry._isAlternative ? (lang === 'local' ? '备选' : 'Alt') : L('optional', lang)}` → `{L('optional', lang)}`
- **Test fixture hint**: for AC1's M3 cross-file 2-source test, instead of file-system fixtures, dev can call `_duplicate_transit_findings(target=Path('timeline.json'), transportation_data={'days': [{'intra_city_routes': {'route_1': {'name_base': 'G5415 HSR'}}}]}, timeline_data={'days': [{'timeline': {'G5415 HSR': {}}}]}, severity='WARN')` directly. This avoids collision with the parent QA's existing on-disk fixtures.
