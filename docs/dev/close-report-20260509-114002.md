**QA assessment**: REAL hole. **NEW within this diff's scope.** The `_check_gaode_read` function in `pretool-tool-policy.py:136-143` checks only `tool_input.get("file_path") or tool_input.get("path")`. The implementation does NOT cover Glob's `pattern` parameter, leaving a documented spec-required surface unenforced.

**Severity**: This is a real bypass. A banned agent (e.g., `meals`) could `Glob(pattern=".claude/skills/gaode-maps/**")` to enumerate the gaode skill source files, then `Read(file_path="<discovered_path>")`. The Read step IS blocked, so the read itself fails; but the Glob discovery succeeds. Lower-impact than a full bypass, but it does violate the spec's literal §5.13C clause 1 acceptance criterion.
