## Blockers (CLOSE: NO)

### Blocker 1 — AC8/AC24: Approve Day stage field from wrong data shape
`effectiveDay` is built from PLAN_DATA which has `stage: None`. The Approve button reads `day.stage` (from effectiveDay/PLAN_DATA) for its "Approved" label — always None, button always shows "Approve" never "Approved" after clicking.
**Fix**: Read `editorDay && editorDay.stage === 'user-selected'` instead.

### Blocker 2 — AC20: Cross-meal client-side copy dead code
`applySelection()` contains cross-meal copy logic (origin_slot_id) but is never called. Drag and tap paths call `window.setEditorSelection` / `window.applyEditorSelection` which skip the client-side copy.
**Fix**: Implement cross-meal copy inside the `window.setEditorSelection` bridge when `originSlotId` is provided.

### Blocker 3 — AC22: data-droppable guard not enforced in handlers
`isGated` sets `data-droppable="false"` visually but `onDragOver`, `onDrop`, and tap-to-select onClick handlers don't check the attribute — drops into skipped/missing slots are not blocked.
**Fix**: Check `e.currentTarget.getAttribute('data-droppable') === 'false'` at the start of each handler.
