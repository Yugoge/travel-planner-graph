## Out-of-scope observations (for future cycles)

1. **Save-reload race** — `saveMutations` should use
   `fetch(..., { keepalive: true })` and/or a localStorage pending-save
   outbox to survive a hard reload mid-flight.
2. **Server-side slot-key allow-list** — `_get_or_create_slot` in
   `save.py:65` accepts any `slot_id`. Defense-in-depth check against
   `day.schema.json` slot allow-list would catch any future front-end
   regression.
3. **Stage-gate on save** — currently `/api/save` does not run
   `_check_stage_gate`. A user-deselect on stage `user-selected`
   produces a transient `STAGE_GATE_VIOLATION`-eligible state on disk
   that surfaces only at validation time, not save time.
