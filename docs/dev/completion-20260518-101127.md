2. **stale `.catch` guard missing in `fetchRoute`**: the `.catch` handler at line 2418 sets `{status: 'error'}` without the monotonic `routeSeqRef` stale-sequence guard, so a slow failing request could overwrite a newer successful result in `routeCache`; fix: add `if (routeSeqRef.current[pairKey] !== seq) return;` inside `.catch`
