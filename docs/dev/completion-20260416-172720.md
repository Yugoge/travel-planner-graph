## Requirement

**Source**: `docs/dev/specs/spec-20260416-172720.md` (user-authored spec, Option C pre-approved)

**Summary**: Fix silent data loss bug where `merge_agent_days` replaces the entire day object instead of merging at slot level. When a POI agent emits a partial day (e.g., only `dinner`), existing `breakfast`/`lunch` were silently wiped.

## Root Cause

**Layer**: L4 (logic/data-flow)

**Broken line**: `scripts/lib/json_io.py:367` — `existing_days_map[day_num] = update_day` performs whole-day replacement. Missing a key-level merge for slot-scoped updates vs. whole-day recalculation.

**Evidence**: commit `47fccd4` (2026-04-13 13:14) dropped Day 2 in `data/china-20260412-092624/meals.json` from 3 slots to 1 slot, while the modification log recorded only `changed_fields: ["days[1].dinner"]`.

## Implementation

**Approach**: New `--merge-slots` flag + new `merge_agent_slots()` function. Existing `--merge-days` behavior unchanged for timeline agent (backward compat).
