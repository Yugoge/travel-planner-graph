## Goal

Three bugs in `CandidatesSidebar` (right panel of `scripts/lib/react_template.tpl`): drag-and-drop is architecturally broken (candidate payloads missing `direction` discriminator; board onDrop never calls `saveMutations` for candidate drops), candidate cards use a completely different compact design than the left KanbanView cards, and all section labels are hardcoded bilingual strings that ignore the `lang` state.

## Section 1 (Before): Current Broken State

**Bug A — DnD**

Board slot cards emit `{ direction: 'board', sourceSlotId, optionId }`. Candidate cards at lines 2427–2431 (accommodation), 2473–2479 (meals), 2521–2524 (activities) emit `{ optionId, slotId, originSlotId }` — no `direction` field, no `sourceSlotId`. The board's `onDrop` at lines 913, 998, 1084, 1170, 1928 gates on `payload.direction === 'board' && payload.sourceSlotId && saveMutations` to call `saveMutations`; candidate drops fail both conditions and fall through to the `window.setEditorSelection` legacy bridge, which saves but also risks mutating the origin slot for cross-meal drops. The accommodation board onDrop at line 1320 has NO `direction === 'board'` gate at all (always uses the legacy bridge). `handleSidebarDrop` at line 2354 checks `direction === 'plan-to-candidates' || direction === 'board'` — candidate cards have neither, so even board→sidebar deselect works for board cards only.

**Bug B — Visual design**

`candidateCardStyle` (lines 2266–2274) produces compact text-only cards: no image region, no fixed width/height, wrong background colors (`#eff6ff`/`#e9f5ec`/white), `cursor: 'grab'`, `padding: '8px 10px'` flat, no category-color header, no `RedNoteLink`, no hover transform. Image region at line 869 is 140px height. Category label row with emoji at line~874. Name row with `RedNoteLink` at line~880.

**Bug C — i18n**

`slotLabels` (lines 2313–2317) is a hardcoded static object with bilingual slash-strings (`'早餐 / Breakfast'`, etc.) — never re-evaluated when `lang` changes. Panel header at line 2405 is `'Candidates — Day ' + dayNum` (English-only). Section headers at lines 2415 and 2461 are `'住宿 / Accommodation'` and `'餐饮 / Meals'` — both hardcoded bilingual. ## Edge Cases & Risks

1. **`sourceSlotId` must NOT be in candidate payloads.** If set, the board's `direction === 'board'` branch would fire if someone adds a naive `|| direction === 'candidates'` without a sub-branch — it would clear the candidate's slot. The fix must use a distinct `direction === 'candidates'` sub-branch that explicitly skips source-slot clearing.

2. **`meals-any` is not a real persisted slot.** The `originSlotId` in the meals candidate payload is the actual origin slot (`rawOpt._originSlotId`). The drop handler must use `originSlotId` (not `slotId`) as `origin_slot_id` for the mutation.

3. **`.slot-drop` overlay in candidate cards.** Each candidate card must contain a `.slot-drop` overlay div with `data-slot-id`, `data-droppable="true"`, `onDragOver`, and `onDrop` handlers. Without this, the board's drop logic (which fires on the overlay) cannot receive the drop. Candidate cards are never gated (no skipped/late-arrival state), so `data-droppable` is always `'true'`.

4. **`cardStyle` / `hoverOn` / `hoverOff` scope.** These are defined inside the `KanbanView` closure (line 802+). `CandidatesSidebar` is a separate component and cannot access them directly. Dev must extract to module scope or inline equivalent constants. Inlining is acceptable for this cycle.

5. **`cardW`/`cardH`/`imgH` responsive values.** Board uses `sm ? 240 : 280` / `sm ? 300 : 320` / `sm ? 120 : 140`. `CandidatesSidebar` does not currently receive `bp`/`sm`. For simplicity, use desktop values (280/320/140) as constants inside `CandidatesSidebar`, or pass `bp` as a prop (preferred but optional).

6. **`handleSidebarDrop` non-regression.** This handler (lines 2347–2360) handles `direction === 'board'` drops — must not be touched. The fix only adds a new `direction === 'candidates'` branch in the board-side `onDrop` handlers.

7. **i18n fallback safety.** `L(key, lang)` returns the raw key string if the key is absent from `ui_labels`. Using `L()` alone for `slotLabels` may return `'morning_activity'` as fallback. Dev must use `getSlotLabel` helper with explicit ternary fallbacks for all 6 slot keys.

8. **AC5/AC6 i18n scope is chrome only.** Candidate card POI names (`.name_local`, `.name_base`) are data, not chrome — they must remain `lang`-conditional but are not bilingual slash-strings. Do NOT replace them. Only the static section headers, panel title, loading/empty texts, and slot labels must be fixed.
